# Chrome-style サイレントアップデートアーキテクチャ

## 自動更新サービス

- 対象クラス: UpdateService

**設計判断 (Why this algorithm?)**

- **Chrome-style アップデート (終了時更新)**:
  アップデートの存在をユーザーに通知して作業を中断させるのではなく、バックグラウンドでサイレントにインストーラーをダウンロードし、アプリ終了時に自動的にインストーラーを起動する設計を採用しました。これにより、ユーザーの作業フローを妨げずに次回起動時に最新版を提供できます。
- **内部での `Task.Run` の不使用**:
  ライブラリ/サービス側の非同期メソッド内で勝手にスレッドプールを消費する（`Task.Run`でラップする）アンチパターンを避けるため、I/Oバウンドな非同期操作として `async` を提供し、呼び出し元のUI層がスレッドプールへのオフロードを制御できるように設計しています。
